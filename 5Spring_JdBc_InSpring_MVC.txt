Step 5 Configure DataSource
@Bean
public DataSource dataSource(){

            new DriverManagerDataSource();

    ds.setUrl("jdbc:mysql://localhost:3306/springjdbc");

    ds.setUsername("root");

    ds.setPassword("root");

    return ds;
}

Step 8 DAO Implementation
@Repository
public class StudentDaoImpl implements StudentDao {

    @Autowired
    private JdbcTemplate jdbcTemplate;

    @Override
    public int save(Student student) {

        String sql="insert into student(name,email,course) values(?,?,?)";

        return jdbcTemplate.update(sql,

                student.getName(),

                student.getEmail(),

                student.getCourse());

    }

    @Override
    public List<Student> getAllStudents() {

        String sql="select * from student";

        return jdbcTemplate.query(sql,new BeanPropertyRowMapper<>(Student.class));

    }

    @Override
    public Student getStudentById(int id) {

        String sql="select * from student where id=?";

        return jdbcTemplate.queryForObject(sql,

                new BeanPropertyRowMapper<>(Student.class),

                id);

    }

    @Override
    public int update(Student student) {

        String sql="update student set name=?,email=?,course=? where id=?";

        return jdbcTemplate.update(sql,

                student.getName(),

                student.getEmail(),

                student.getCourse(),

                student.getId());

    }

    @Override
    public int delete(int id) {

        String sql="delete from student where id=?";

        return jdbcTemplate.update(sql,id);

    }

}

Step 10 Controller
@Controller
public class StudentController {

    @Autowired
    StudentService service;

    @GetMapping("/")
    public String home(Model model){

        model.addAttribute("students",service.getAllStudents());

        return "home";

    }

    @GetMapping("/add")

    public String addStudent(){

        return "addStudent";

    }

    @PostMapping("/save")

    public String save(@ModelAttribute Student student){

        service.save(student);

        return "redirect:/";

    }

    @GetMapping("/edit/{id}")

    public String edit(@PathVariable int id,Model model){

        model.addAttribute("student",

                service.getStudentById(id));

        return "updateStudent";

    }

    @PostMapping("/update")

    public String update(@ModelAttribute Student student){

        service.update(student);

        return "redirect:/";

    }

    @GetMapping("/delete/{id}")

    public String delete(@PathVariable int id){

        service.delete(id);

        return "redirect:/";

    }

}

Complete Flow (Internal Working)

When a user visits http://localhost:8080/, the request first reaches the DispatcherServlet (the Front Controller). The DispatcherServlet asks the HandlerMapping which controller should handle the request. It finds the method mapped to / in StudentController.

The controller calls StudentService, which contains the business logic. The service delegates the work to StudentDao. The DAO uses JdbcTemplate to execute SQL queries. JdbcTemplate obtains a connection from the configured DataSource, runs the SQL against MySQL, maps the result to Student objects, and returns them to the DAO.

The returned data flows back through the layers:

MySQL
   ↑
JdbcTemplate
   ↑
DAO
   ↑
Service
   ↑
Controller
   ↑
Model
   ↑
DispatcherServlet
   ↑
ViewResolver
   ↑
home.jsp
   ↑
Browser

The Model carries the data (for example, the list of students) from the controller to the JSP. The InternalResourceViewResolver converts the logical view name "home" into the actual JSP path:

"home"
      ↓
/WEB-INF/views/home.jsp

The JSP renders the HTML, which is sent back to the browser.

This is the classic Spring MVC + Spring JDBC architecture that many companies used before Spring Boot. Once you're comfortable with this flow, you'll find that moving to Spring Data JPA mainly replaces the DAO's manual SQL with repository interfaces, while the overall MVC request flow remains very similar.
