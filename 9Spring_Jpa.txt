What is Spring JPA?
First, understand one important thing.

Many students say Spring JPA, but technically there is no separate technology called Spring JPA.

Usually people mean

Spring Framework + Spring ORM + JPA (Hibernate implementation)

    @Id

    private String city;

    public Student() {}

    public Student(String name, String city) {
        this.name = name;
        this.city = city;
    }

    // getters setters
}
Spring Configuration
@Configuration
@ComponentScan("com.example")
@EnableTransactionManagement
@PropertySource("classpath:application.properties")
public class AppConfig {

    @Autowired
    Environment env;

    @Bean
    public DataSource dataSource(){

        DriverManagerDataSource ds=new DriverManagerDataSource();

        ds.setDriverClassName(env.getProperty("db.driver"));
        ds.setUrl(env.getProperty("db.url"));
        ds.setUsername(env.getProperty("db.username"));
        ds.setPassword(env.getProperty("db.password"));

        return ds;
    }

    @Bean
    public LocalContainerEntityManagerFactoryBean entityManagerFactory(){

        LocalContainerEntityManagerFactoryBean emf =
                new LocalContainerEntityManagerFactoryBean();

        emf.setDataSource(dataSource());

        emf.setPackagesToScan("com.example.entity");

        HibernateJpaVendorAdapter adapter =
                new HibernateJpaVendorAdapter();

        emf.setJpaVendorAdapter(adapter);

        Properties prop=new Properties();

        prop.put("hibernate.hbm2ddl.auto","update");
        prop.put("hibernate.show_sql","true");

        emf.setJpaProperties(prop);

        return emf;
    }

    @Bean
    public PlatformTransactionManager transactionManager(
        EntityManagerFactory emf){

        return new JpaTransactionManager(emf);
    }

}
DAO Interface
public interface StudentDAO {

    void save(Student student);

    Student getById(int id);

    List<Student> getAll();

    void update(Student student);

    void delete(int id);

}
DAO Implementation
@Repository
public class StudentDAOImpl implements StudentDAO {

    @PersistenceContext
    private EntityManager entityManager;

    @Override
    public void save(Student student) {

        entityManager.persist(student);

    }

    @Override
    public Student getById(int id) {

        return entityManager.find(Student.class,id);

    }

    @Override
    public List<Student> getAll() {

        return entityManager
                .createQuery("from Student",Student.class)
                .getResultList();

    }

    @Override
    public void update(Student student) {

        entityManager.merge(student);

    }

    @Override
    public void delete(int id) {

        Student s=entityManager.find(Student.class,id);

        if(s!=null){

            entityManager.remove(s);

        }

    }

}
Service Interface
public interface StudentService {

    void save(Student student);

    Student getById(int id);

    List<Student> getAll();

    void update(Student student);

    void delete(int id);

}
Service Implementation
@Service
@Transactional
public class StudentServiceImpl implements StudentService {

    @Autowired
    StudentDAO dao;

    @Override
    public void save(Student student) {

        dao.save(student);

    }

    @Override
    public Student getById(int id) {

        return dao.getById(id);

    }

    @Override
    public List<Student> getAll() {

        return dao.getAll();

    }

    @Override
    public void update(Student student) {

        dao.update(student);

    }

    @Override
    public void delete(int id) {

        dao.delete(id);

    }

}
Main Class
public class Main {

    public static void main(String[] args) {

        AnnotationConfigApplicationContext context =
                new AnnotationConfigApplicationContext(AppConfig.class);

        StudentService service =
                context.getBean(StudentService.class);

        // INSERT
        service.save(new Student("Harshal","Jaipur"));

        // GET
        Student s=service.getById(1);

        System.out.println(s.getName());

        // UPDATE
        s.setCity("Delhi");

        service.update(s);

        // GET ALL

        service.getAll().forEach(System.out::println);

        // DELETE

        service.delete(1);

    }

}

EntityManager Methods Used
Method	Purpose
persist()	Insert new entity
find()	Get entity by primary key
merge()	Update detached entity
remove()	Delete entity
createQuery()	Fetch multiple records
createNamedQuery()	Run named JPQL query

Difference from Standalone Hibernate
Standalone Hibernate	Spring + JPA
SessionFactory	EntityManagerFactory
Session	EntityManager
Manual transaction (beginTransaction())	@Transactional
Manual session close	Spring manages lifecycle
session.save()	entityManager.persist()
session.update()	entityManager.merge()
session.delete()	entityManager.remove()
session.get()	entityManager.find()
What You'll Learn Next
Once you're comfortable with this style, the next step is Spring Data JPA (without Spring Boot), where you won't write the DAO implementation yourself. Instead, you'll create an interface like:

public interface StudentRepository extends JpaRepository<Student, Integer> {
}
and Spring Data JPA will automatically provide implementations for CRUD methods such as save(), findById(), findAll(), and deleteById(). This significantly reduces boilerplate code and is the foundation for how persistence is typically done in modern Spring Boot applications.
