1. Spring + Hibernate (Traditional Spring)

You configure almost everything yourself.

You create:

DataSource
SessionFactory
HibernateTransactionManager
Component scanning
Transaction management
XML or Java configuration

Example:

@Configuration
@EnableTransactionManagement
public class AppConfig {

    @Bean
    public DataSource dataSource() {
        // Database configuration
    }

    @Bean
    public LocalSessionFactoryBean sessionFactory() {
        // Hibernate configuration
    }

    @Bean
    public HibernateTransactionManager transactionManager() {
        // Transaction Manager
    }
}

DAO:

@Repository
public class StudentDao {

    @Autowired
    private SessionFactory sessionFactory;

    @Transactional
    public void save(Student student) {

        sessionFactory
            .getCurrentSession()
            .save(student);
    }
}

Notice how much configuration you wrote.

2. Spring Boot + Hibernate (Modern Way)

You don't create those beans manually.

Just add dependency:

spring-boot-starter-data-jpa

Then write:

spring.datasource.url=jdbc:mysql://localhost:3306/studentdb
spring.datasource.username=root
spring.datasource.password=root

spring.jpa.hibernate.ddl-auto=update

That's it.
